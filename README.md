# تخيل فضاء الرياضيات | Math Space

مختبر رياضيات عربي تفاعلي يعمل محليًا في المتصفح. هذه **نسخة أولى عاملة**، وليست تنفيذًا كاملًا لجميع بنود المواصفات الـ84. لا توجد صفحات وهمية أو نتائج مولدة بالذكاء الاصطناعي؛ المجالات المؤجلة مذكورة أدناه.

## التشغيل

المتطلبات: Node.js 22.16 أو أحدث متوافق مع Vite 8، وnpm.

```sh
npm install
npm run dev
npm test
npm run lint
npm run build
npm run preview
```

عنوان التطوير المعتاد: http://localhost:5173/. أمر موثوق لتحديد المنفذ في PowerShell:

```sh
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5173 --strictPort
```

## ما يعمل الآن

- مساحة عمل لحل المعادلات الخطية والتربيعية، بما فيها المعاملات على الطرفين والجذور المركبة، مع خطوات وسبب وقاعدة لكل تحويل مدعوم.
- محرّر واحد للمسألة في مساحة العمل؛ تبويب «الكتابة» يركّز عليه بدل تكراره. اللوحة الرياضية قابلة للإخفاء وتضم أقسامًا للأساسيات والقوى والجذور والمثلثات واللوغاريتمات والتفاضل والتكامل والمتغيرات والثوابت، مع حذف التحديد وتحريك المؤشر. القوالب تطبّق على التحديد، بينما الاشتقاق والتكامل على التعبير كاملًا بالنسبة إلى x. الزوايا بالراديان والجذور الكسرية للقيم غير السالبة، ولا تضيف اللوحة دعمًا للنهايات أو التكامل المحدد أو حل كل أنواع المسائل.
- في «بُعد آخر للفهم»، تبويب «الكتابة» يفتح وضع سطح الدالة ويركّز على محرّر السطح نفسه؛ لا ينشئ محرّرًا أو لوحة مفاتيح ثانية، وتبقى المسودة محفوظة عند التنقل بين المجسمات والسطح.
- لوحة رموز ومعاينة رياضية للإدخال في مساحة العمل وأدوات الكتابة والسطح ثلاثي الأبعاد: جيب وجيب تمام وظل، جذور وكسور وأسّيات ولوغاريتمات، وتكامل غير محدد واشتقاق بالنسبة إلى x. يقبل الإدخال `sin(x)` و`ساين(x)` و`جا(x)`، والأرقام العربية، و`∫ sin(x) dx` أو `integral(sin(x))` و`derivative(x^3)`. نتيجة التكامل تضيف `C`، والرسم يعرض اختيار `C = 0`. هذا ليس محللًا عامًا لكل صيغ LaTeX أو للتكاملات المحددة وغير الصحيحة.
- مكتبة ومستشار وإدخال يدوي داخل مساحة العمل ومعمل ثلاثي الأبعاد والإثبات البصري؛ اختيار أمثلة قوانين مناسبة للتجربة والاطلاع على جميع مفاهيم المكتبة دون مغادرتها. التعبير المخصص في الإثبات البصري يعرض استكشافًا بيانيًا، لا برهانًا عامًا.
- مستشار حتمي قائم على القواعد: يصنف المسألة، يختار الطريقة ويبررها، يعرض البدائل والتلميحات، ويتحقق من تكافؤ مجموعة الحلول الحقيقية بين خطوتين خطيتين أو تربيعيتين.
- رسم Canvas لدوال حقيقية: تحريك وتكبير وتصغير، شبكة ومحاور، مقارنة منحنيات، تحديد نقطة وقيمة وميل تقريبي، مماس، وتصدير PNG. توجد أمثلة لـ13 عائلة دوال.
- معاملات تربيعية تفاعلية مع تفسير انتقال المنحنى وتغير شكله، وتبسيط وتوسيع وتحليل واشتقاق وتكامل رمزي للتعبيرات التي يدعمها المحرك.
- برهان بصري متحرك لمربع مجموع، ومقارنة مساحات لمثلث 3–4–5. المقارنة الأخيرة ليست برهانًا عامًا لفيثاغورس.
- الرسم ثابت دون حركة دورية. تعديل التعبير في الإثبات البصري أو مساحة العمل يحدّث الدالة مباشرة؛ تغيير الأرقام أو معاملات `a` و`b` و`c` ينقل المنحنى إلى الشكل الجديد بحركة واحدة مدتها 350 مللي ثانية ثم يثبت. التعديلات المتتابعة تبدأ من الشكل المعروض وتتجه إلى آخر قيمة. تفضيل تقليل الحركة يعرض النتيجة مباشرة. الإدخال غير المكتمل أو غير الصالح في الإثبات البصري يعرض رسالة ويبقي آخر رسم صالح. تدعم التجربة طرفي المعادلة والدوال القابلة للرسم؛ الانتقال البصري ليس إثباتًا عامًا أو دالة رياضية وسيطة.
- هندسة الدائرة والمستطيل والمثلث والقطعة المستقيمة، مع قياسات وتفسير وموضع رأس مثلث قابل للسحب.
- دائرة الوحدة والمثلثات وزوايا بالدرجات والراديان، ورسوم الجيب وجيب التمام والظل؛ وتمثيل قطبي للأعداد المركبة وصيغة أويلر.
- مختبر النهايات العددي، والقاطع والمماس والمشتقة، والتكامل بمستطيلات المنتصف مع دالة أصلية حين تتوفر.
- مشهد Three.js: ستة مجسمات بأبعاد ومساحات وحجوم محسوبة، ودوران وتكبير بالكاميرا، وسطح z=f(x,y).
- متجهات ثنائية الأبعاد، جمع وضرب قياسي ومركبة الضرب المتجهي؛ مصفوفة 2×2 وتحويل الشبكة ومحدد؛ تقاطع معادلتين خطيتين وحالات التوازي والتطابق.
- إحصاء مجموعة بيانات المستخدم: المتوسط والوسيط والمنوال وتباين المجتمع والانحراف المعياري ومدرج ومخطط صندوقي؛ تجارب فعلية شبه عشوائية لعملة ونرد مع مقارنة الاحتمال النظري والتجريبي.
- متتاليات حسابية وهندسية ومجاميعها؛ تقريب موجة مربعة بمتسلسلة فورييه وحساب DFT فعلي لإشارة قابلة للتعديل.
- خوارزمية إقليدس وGCD وLCM دقيق بأعداد صحيحة كبيرة، وبواقي القسمة والقواسم وفحص أولية ضمن حدود المختبر؛ التباديل والتوافيق ومثلث باسكال.
- تدريب بمسائل خطية وتربيعية مولدة حسابيًا، تلميحات وحل تدريجي وتحقق من الإجابة، وأربعة مستويات.
- مكتبة من 22 موضوعًا مع صيغة ومفهوم وسبب واستخدام ومثال وأخطاء وروابط مرتبطة؛ بحث عربي وإنجليزي، مفضلة وسجل محليان، ووضعان فاتح وداكن وتصميم متجاوب.

## البنية

- `src/engine/calculation.ts`: حساب جذور التربيعية مستقلًا عن واجهة العرض.
- `src/engine/advisor.ts`: اختيار الطريقة والبدائل بقواعد حتمية.
- `src/engine/explanation.ts`: عقد خطوة محسوبة + سبب، وقوالب القواعد؛ يرفض الخطوة التي لا تحمل تفسيرًا.
- `src/engine/math.ts`: تحليل AST الآمن، تصنيف المسألة، تجميع خطوات الحل، والتنسيق والعمليات الرمزية.
- `src/engine/simulations.ts`: حسابات الإحصاء والأعداد والتوافقيات وريمان والطيف.
- `src/content/knowledge.ts`: بيانات المكتبة وأمثلة الدوال والمجالات المستقبلية.
- `src/components`: مساحة العمل والرسم وعناصر التحكم والمختبرات والمكتبة والمشهد الثلاثي الأبعاد.
- `src/App.tsx`: التنقل والبحث والإعدادات والسجل والمفضلة.

المكتبات المستخدمة: React وTypeScript وVite وmathjs وNerdamer وThree.js وKaTeX وLucide. الخطوط مثبتة محليًا. **لا ChatGPT ولا LLM ولا API ذكاء اصطناعي، ولا مفاتيح أو خدمات سحابية.** الاختبارات موجودة بجوار المحركات وتعمل بـVitest.

لإضافة موضوع: أضف سجلًا إلى `topics` به معرف فريد، الصيغة والتفاصيل والسبب والمثال والأخطاء والمراجع الصحيحة إلى موضوعات موجودة. للتفاعل الجديد، أضف حسابًا مستقلًا واختباره ثم مكوّن مختبر واربطه في `View` والتنقل. ولنوع مسألة جديد، أضف مسار تحليل وخطوات موثقة وتوصيات واختبارات في المحرك؛ لا تحول المسألة غير المدعومة إلى حل تخميني.

## الحدود العلمية

- المحلل يقبل تعبيرات رياضية مقيدة، لا شفرة عامة. المعادلات غير الخطية خارج الدرجة الثانية لا تحصل على خطوات حل مزعومة؛ لا يوجد محلل عام للمتباينات أو أنظمة المعادلات غير الخطية.
- المقارنات العددية والرسوم والميل تعتمد على أعداد عائمة وأخذ عينات. العرض يقرب غالبًا إلى ست منازل، ويستخدم الصيغة العلمية للقيم الصغيرة جدًا والكبيرة؛ الرسم ليس دليلًا رياضيًا.
- رسم سطح ثلاثي الأبعاد محدود بـ[-3,3] لكل من x وy، ويقص الارتفاع إلى [-8,12]؛ لا يعد هذا عرضًا لكامل مجال الدالة.
- التكامل غير المحدد يعتمد على دعم Nerdamer. فرق قيم الدالة الأصلية ليس حلًا عامًا للتكاملات غير الصحيحة؛ فحص المجال العددي يرفض القيم غير المعرفة التي يرصدها، لكنه لا يثبت الاستمرارية أو التقارب ولا يضمن كشف جميع نقاط التفرد.
- فحص الخطوات يقارن مجموعات الحلول الحقيقية للأنواع المدعومة، وليس تحققًا عامًا من كل قاعدة رمزية أو مجال أو حلول مركبة.
- تباين الإحصاء تباين مجتمع لا عينة. أرباع الصندوق باستيفاء خطي والشوارب عند أصغر وأكبر قيمة، وليست مخطط Tukey للكشف عن القيم الشاذة.
- الاحتمال تجارب عملة ونرد عادلة فقط؛ العشوائية عبر المتصفح وليست مناسبة للاستخدامات الأمنية.
- المفضلة والسجل والمظهر محفوظة بـlocalStorage على هذا المتصفح. سجل المحاكاة يحفظ فتح المختبر، وليس جميع معاملات التجربة أو الكاميرا. لا حسابات أو مزامنة أو مشاركة سحابية.

## مجالات مؤجلة

المتباينات وحل المعادلات المثلثية العام، الدوال متعددة التعريف، إنشاء هندسي حر، براهين هندسية عامة، تفاضل متعدد المتغيرات، معادلات تفاضلية وحقول اتجاه، مصفوفات عامة وقيم ومتجهات ذاتية، انحدار واختبارات إحصائية، احتمال شرطي وBayes وأوراق لعب، تحويل Laplace وتحويلات إضافية، ومناهج شاملة لكل مجال. البنية الحالية تسمح بإضافتها تدريجيًا، لكنها لا تقدمها كميزات مكتملة.

## التحقق

الاختبارات تغطي المعادلات والجذور والتفسيرات والمدخلات الآمنة والعمليات الرمزية، ودقة القيم الصغيرة، والإحصاء وGCD/LCM والتوافيق وريمان وDFT والبحث وروابط المكتبة. فُحصت التفاعلات والرسوم والـWebGL والمظهر والاستجابة في المتصفح على الحاسوب والهاتف. وجود مكتبات رمزية كبيرة قد ينتج تحذير حجم حزمة من Vite؛ تقسيم وتحميل جميع الوحدات الثقيلة عند الطلب عمل تحسين لاحق.
